# Project Wiki

This directory stores stable project knowledge and long-lived facts.

Use subdirectories by knowledge type:

- `business/` — business concepts, workflows, terminology and rules
- `api/` — API contracts, field meanings and integration notes
- `database/` — schema semantics, identifiers, relationships and data rules
- `integrations/` — external systems and third-party integration knowledge

Do not store temporary session notes, current task status, or short-lived implementation details here.
