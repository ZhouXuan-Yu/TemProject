# Git Rules

- Do not force-push shared branches without explicit approval.
- Do not use destructive history rewrites on shared branches without approval.
- Keep commits focused and scoped to the requested change.
- Do not commit generated secrets, credentials, runtime caches, or local-only configuration.
- Prefer feature branches for risky or wide-ranging changes.
- Before deleting branches or reverting major changes, verify the target and impact.
